# NAPIER v2.0

National Airfare Price Index Engine: live one-way fares (SerpApi → Google Flights), holiday-demand projections, and an archived Jevons index.

```
backend/   FastAPI  (app/ = API, napier_scraper.py = archive job, napier_engine.py = index job)
frontend/  Next.js 16 + Tailwind v4 + React 19 (Spatial Glass UI, light/dark mode)
```

## Quickstart

```bash
# Backend setup
cd backend && cp .env.example .env     # set SERPAPI_KEY (required for live prices)
pip install -r requirements.txt
uvicorn main:app --reload --port 8000

# Frontend setup
cd frontend && cp .env.example .env.local
npm install && npm run dev
```

## Price Accuracy

- **Google Flights Alignment & `SERPAPI_GL`**: Fare searches target regional points of sale. `SERPAPI_GL` (default `"in"`, configurable in `backend/app/core/config.py`) pins queries to India so quotes match Google Flights India. The region is embedded in the fare cache key (e.g. `fares:{gl}:{origin}-{destination}:{date}`).
- **Indicative Fares**: All displayed fares are indicative live estimates sourced directly from Google Flights via SerpApi. Airlines dynamically update pricing and seat availability in real time, so prices may fluctuate between search time and final airline checkout. Direct booking links use SerpApi `booking_token` or `departure_token` when available, falling back to Google Flights search links.
- **Cache Window & Timestamps**: Live fare queries are cached for 30–60 minutes (`CACHE_TTL_SECONDS`, default 2700 seconds / 45 minutes) across Redis, Supabase `fare_cache`, or in-process memory. Every cached and live quote returns an ISO-8601 UTC `fetched_at` timestamp, displayed in the carrier card header (e.g. *Fares fetched at HH:MM <timezone>*).
- **Strict Data Integrity**: Prices are never synthesised or estimated. If SerpApi fails or `SERPAPI_KEY` is omitted, the API responds with `503 LIVE_DATA_UNAVAILABLE` and the UI reflects this state.

## Heuristic Forecasting

- Forecasts are rule-based demand adjustments (`live fare × holiday factor`), not black-box estimates.
- Multi-year Indian festival lookup dynamically identifies holidays (Diwali, Holi, Christmas, New Year, Independence Day, etc.) across current and future years using the `holidays` library.

## Database Schema (Supabase)

```sql
-- Live fare cache table (optional; fallback when Redis is not used)
create table if not exists fare_cache (
  cache_key  text primary key,
  payload    jsonb not null,
  expires_at timestamptz not null
);

-- Raw flight prices collected by napier_scraper.py
create table if not exists raw_flight_prices (
  id bigint generated by default as identity primary key,
  route_code text not null,
  origin text not null,
  destination text not null,
  lead_time_days integer not null,
  price double precision not null,
  departure_date date not null,
  scraped_at timestamptz default now()
);

-- Jevons price index metrics computed by napier_engine.py
create table if not exists airfare_index_metrics (
  id bigint generated by default as identity primary key,
  calculation_date date not null,
  route_code text not null,
  lead_time_days integer not null,
  sample_count integer not null,
  avg_base_fare double precision not null,
  avg_total_fare double precision not null,
  jevons_index_value double precision not null,
  mom_change_pct double precision not null
);
```

### Metrics Schema Notes:
- `avg_total_fare`: Average fare across clean price samples (IQR-filtered) for that route and lead time, stored alongside `avg_base_fare` for schema parity.
- `mom_change_pct`: Stores `round(jevons_index_value - 100.0, 2)`, measuring the percentage deviation of the geometric mean fare relative to the benchmark base fare (4,000 INR), rather than a calendar month-over-month delta.

## Configuration (.env)

| Variable | Location | Default | Description |
|---|---|---|---|
| `PROJECT_NAME` | `backend` | `"NAPIER AI Engine"` | API project title |
| `PORT` | `backend` | `8000` | Port for uvicorn server |
| `SERPAPI_KEY` | `backend` | `None` | SerpApi key for Google Flights scraper |
| `SERPAPI_GL` | `backend` | `"in"` | Two-letter country code for Google Flights search |
| `CACHE_TTL_SECONDS` | `backend` | `2700` | Fare cache TTL (clamped to 1800–3600 seconds) |
| `REDIS_URL` | `backend` | `None` | Optional Redis cache connection string |
| `SUPABASE_URL` | `backend` | `None` | Supabase project URL |
| `SUPABASE_KEY` | `backend` | `None` | Supabase anon/service key |
| `ALLOWED_ORIGINS` | `backend` | `"*"` | Comma-separated CORS allowed origins |
| `NEXT_PUBLIC_API_URL` | `frontend` | `"http://localhost:8000"` | Backend API base URL for Next.js |
